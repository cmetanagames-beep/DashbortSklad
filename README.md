# DashbortSklad

Складской дашборд AKFIX с актуальными данными из воронки «Сопровождение продаж / Отгрузки» в Bitrix24.

## Возможности

- заказы от стадии «Передано на склад» до «Груз проверен»;
- статистика по стадиям, суммам и способам доставки;
- плановая загрузка склада по рабочим дням;
- количество товаров из текстового слоя PDF-счетов;
- история производительности склада;
- контроль фотографий Балашихи и Мытищ;
- архив контроля фото с выбором даты или диапазона;
- автоматическое обновление каждые 30 секунд;
- настраиваемый порядок и видимость карточек;
- защищённый вход для сотрудников.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
cp config.example.json config.local.json
npm run create-password
npm start
```

Перенесите полученные `salt` и `passwordHash` в `config.local.json`, затем укажите закрытый входящий вебхук Bitrix24 в поле `bitrixWebhook`.

По умолчанию сервер доступен по адресу `http://127.0.0.1:8787`, а дашборд — по адресу:

```text
http://127.0.0.1:8787/warehouse-dashboard/index.html
```

Для другого адреса и порта используйте переменные окружения `HOST` и `PORT`.

## Развёртывание

На сервере рекомендуется запускать приложение через PM2 и проксировать через Nginx:

```bash
npm install --omit=dev
HOST=127.0.0.1 PORT=8787 pm2 start server.js --name dashbort-sklad
pm2 save
```

Файлы `config.local.json`, снимки, кэш PDF и архивы исключены из Git. Никогда не добавляйте вебхук и пароли в репозиторий.
